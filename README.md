## 🚀 HƯỚNG DẪN KHỞI CHẠY

1. Tải bộ mã nguồn từ GitHub về máy.
2. Chạy lệnh `npm install` để cài đặt các thư viện cần thiết.
3. Tạo tệp `.env` và điền `GEMINI_API_KEY`.
4. Chạy `npm start` và truy cập `http://localhost:3000/login.html` trên trình duyệt.
